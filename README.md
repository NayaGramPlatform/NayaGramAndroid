## 🌟 Key Highlights & Exclusive Features

1. **Direct Telegram MTProto 2.0 Encryption:** Direct connection to official Telegram datacenters. Zero middleman servers, zero backdoors.
2. **Stealth & Privacy Hub:** Built-in Ghost Mode, Anonymous Story Viewer, and Local Anti-Delete message protection.
3. **Infonity AI 💎 Integration:** Direct access to `@InfonityAI_Bot` right from settings for smart assistance.
4. **Novagram-Style Channel Pinning:** Silent, crash-proof channel pinning for official updates without intrusive popups.
5. **Bangla & Multilingual Support:** Native Bengali language support alongside full international language choices.
6. **Smart Messaging Suite:** Message scheduler, smart auto-reply, clean forwarding without quote, and instant in-chat translation.
7. **Production App Signing:** Signed with 35-year lifetime certificate (`nayagram-release.jks`) meeting Google Play 2026 standards.

## 🛠️ Build & Architecture

- **Architecture:** Android Native (Java/Kotlin + NDK C++ for WebRTC/ExoPlayer)
- **Min SDK:** 23 (Android 6.0+)
- **Target SDK:** 34 / 35 (Android 14 & 15)
- **Automated CI/CD:** GitHub Actions compiling release `.aab` (Google Play Bundle) and `.apk` on every push.
