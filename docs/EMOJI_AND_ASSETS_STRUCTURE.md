# NayaGram Asset & Emoji Architecture

## 1. TMessagesProj/emoji মিররিং বিবরণ
 ডিরেক্টরিটি -এর সঙ্গে কাঠামো সামঞ্জস্য বজায় রাখার জন্য গিট ট্রি রেফারেন্স () ব্যবহার করে মিরর করা হয়েছে। এর ফলে:
- কোনো বাইনারি ফাইল ডুপ্লিকেট হয়নি এবং রিপোজিটরির সাইজ অপ্রয়োজনীয়ভাবে বৃদ্ধি পায়নি।
- উভয় কাঠামোর পাথ অক্ষত রয়েছে।

## 2. কেন স্ট্যান্ডার্ড অ্যাসেট পাথ (src/main/assets/) বজায় রাখা অপরিহার্য
- **অ্যান্ড্রয়েড আর্কিটেকচার:** Android Gradle Plugin শুধুমাত্র  ডিরেক্টরি থেকে ফাইলগুলো APK এবং Play Store AAB বান্ডেলে প্যাকেজ করে।
- **টেলিগ্রাম রানটাইম লোডার:** C++ () এবং Java লেভেলে ইমোজি ও থিম লোড করার কোড সরাসরি  এবং  রিড করে।
- রুট লেভেলের  থাকলে তা রানটাইমে স্বয়ংক্রিয়ভাবে প্যাকেজ হয় না; তাই  এবং  বজায় রাখা প্লে স্টোর কমপ্লায়েন্স ও রানটাইমে ইমোজি ক্র্যাশ এড়াতে অত্যাবশ্যক।

## 3. ভবিষ্যতে ইমোজি ও অ্যাসেট আপডেট করার নিয়ম
1. **মূল অ্যাসেট আপডেট:** নতুন ইমোজি বা স্প্রাইট যুক্ত করতে হলে প্রথমে  ফোল্ডারে ফাইলগুলো রাখুন বা  পুনর্নির্মাণ করুন।
2. **মিরর সিঙ্ক:** রুট লেভেলের -তেও একই ফাইলগুলো সিঙ্ক রাখুন, যাতে উভয় ডিরেক্টরি একরকম থাকে।
3. **লোকাল যাচাই:**  বা বিল্ড চালিয়ে অ্যাসেট লোডিং টেস্ট করুন।
